## 代码高亮

```python
def fibonacci(n: int) -> int:
    """返回第 n 个斐波那契数"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fibonacci(10))  # 55
```

```javascript
// 一行代码也能高亮
const greet = (name) => `Hello, ${name}!`;
console.log(greet("World"));
```
